
### STL
- C++ STL stands for Standard Template Library. It is a powerful and extensive collection of functions and classes in C++.
- It plays an crucial role in accelarting C++ software development. And also helps in the data structure and algorithm.

### Why we need STL?
- Efficiency
- Reusability/Productivity
- Safety
- Performance Optimization

### Common Components in STL
- Containers: vector, list, queue, stack, set, map etc
- Alog: sort(), binary_search(), reverse() etc
- Iterators
- Functors

#### Containers -
Containers in C++ STL are data structures that are designed to store the data and manage collection of objects

##### Vector: 
- Dynamic array that can grow or shrink in size.
- Allows fast random access to elements.
- Inserting and removal of elements at end is efficient.
